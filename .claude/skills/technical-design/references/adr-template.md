# ADR template

Copy into `docs/02-design/02-technical/{YYYYMMDD}-{NN}-adr-{topic}.md`.

One ADR holds **one** decision. If a document needs the word "และ" in its
title, it is probably two ADRs.

`status`: `เสนอ` → `ยอมรับแล้ว` → `ถูกแทนที่`

A decision is never edited into a different decision. When it changes, write a
new ADR with `supersedes:` pointing back, set the old one to `ถูกแทนที่`, and
move it to `docs/00-archived/` — per `docs/00-archived/index.md`.

---

title: <การตัดสินใจอะไร — วลีสั้น ๆ>

supersedes: []
---

## หมายเหตุเรื่อง `status`

`เสนอ` ต่างจาก `ยอมรับแล้ว` อย่างมีผล — ห้ามเขียนโค้ดตาม ADR ที่ยังเป็น `เสนอ`
ผู้ที่เปลี่ยนสถานะต้องเป็นเจ้าของโปรเจกต์ ไม่ใช่ผู้เขียนเอกสาร
